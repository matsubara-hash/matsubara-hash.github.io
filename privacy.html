プライバシーポリシー

HW Data Connector（以下「本アプリ」）は、運営者が自身の業務で利用する社内向けツールです。

1. 取得する情報

運営者本人が許可した Google アカウントについて、Google ドライブ、Google ドキュメント、Google アナリティクス、Search Console のデータを読み取り専用で取得します。データの作成・変更・削除は行いません。

2. 利用目的

取得したデータは、運営者の業務上の分析・資料作成のためにのみ利用します。

3. 第三者提供

取得したデータを第三者に販売・提供することはありません。広告目的での利用も行いません。

4. 保管

データは運営者が管理する端末および運営者のクラウド環境にのみ保管し、氏名・メールアドレス等の個人情報は保管しない方針で運用します。

5. アクセスの取り消し

Google アカウントの「サードパーティ製のアプリとサービス」設定から、いつでも本アプリのアクセス権を取り消すことができます。

6. Google API サービスのユーザーデータに関するポリシー

本アプリによる Google API から取得した情報の使用は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に準拠します。

7. お問い合わせ

本アプリに関するお問い合わせは、Google のログイン画面に表示されるサポート窓口までご連絡ください。
